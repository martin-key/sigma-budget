# Работа с пакет на издание

`packages/ingest/src/release-client/` запазва каноничния JSON, проверката на манифеста и файловете, Node proof и ограниченото публично HTTP четене за build, validate и reproduce. Името на директорията се запазва за съществуващите импорти.

Командите за публикуване, удостоверяването, разписките за операции и multipart протоколът са премахнати. Новите издания идват чрез [PR с данните](operator-guide.md).
