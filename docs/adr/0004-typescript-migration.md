# ADR 0004 · Пренос към TypeScript

Дата: 8 ноември 2026 г. · Статус: прието

## Решение

Преносът от Python към TypeScript е поетапен, а публикуваното издание остава неизменно. Python запазва всяка операция, докато заместителят ѝ получи равностойни независими проверки. Основата не пренася предметни строители и не заменя `./budget`.

Използват се Node 24, pnpm 10.33.0, Turbo и Vitest по конвенциите на СИГМА. `apps/etl` съдържа офлайн ESM CLI (`budget-ts` по време на миграцията), `packages/ingest` - обработката и сравнението само за Node, `packages/dataset-schema` - платформено независимите DTO и runtime guards, а `packages/test-support` - фикстурите с контролни суми. ADR 0003 продължава да определя Python и web пътищата; настоящото решение заменя неговия абзац за npm. Worker compatibility date остава независима от версията на Node.

## Правило за съответствие

Сравнява се парснат JSON с точни ключове, подредени масиви и точно съвпадение на текстове, булеви стойности, null и канонични десетични низове. Числовият толеранс е абсолютна половин единица при изрично зададена публикувана точност, избрана по набор и JSON Pointer. Идентификаторите, годините, бройките и целочислените парични единици остават точни. Изключението посочва един файл, pointer, стара и нова стойност и основание. Липсващо доказателство е `unverified`, а не успех. Историческите проверки по хеш остават точни; семантичното сравнение не ги заменя.

Кандидатите и отчетите се записват извън `data/release`. Обхватът идва от `data/datasets.yaml`, а файловите множества трябва да съвпадат, включително остарели министерски файлове. До добавянето на адаптери основата отчита останалите формати като `unverified`. YAML регистърът отхвърля дублирани ключове. Инвентарът на фикстурите записва SHA-256, базова ревизия, фиксирана дата и допустимост на възпроизвеждането за всеки набор. Предметните преноси добавят вложените договори и доказателства; основните guards покриват метаданните и горното ниво на DTO.

## Последици

Python CI и образът за обработка се запазват. Качването на staging работи както преди, с pnpm.

## Завършване на производствения пренос · 10 ноември 2026 г.

`./budget` вече изпълнява общия Node CLI. Реалните четци, графът на строителите, всички 26 предметни групи и REGISTRY, пакетът, възпроизвеждането и candidate сайтът са свързани. Отделната команда `./budget-python` запазва стария launcher за исторически Python манифести и референтните проверки. Новите издания не използват Python производител. Публикуваните данни и историческите доказателства остават непроменени; липсващите оригинали продължават да са `unverified`.

Независимото функционално приемане на общата интеграция е успешно. CI bootstrap поправката и смяната на default подлежат на отделно приемане преди merge.
