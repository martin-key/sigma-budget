# Ново издание на данните

Данните се публикуват заедно с кода на „СИГМА Бюджет“.

1. В `midt-bg/sigma-budget-data` се сглобява и проверява новото издание.
2. Отваря се PR към `main` на този проект с обновено копие в `data/release/`, включително цялата `data/release/releases/`. Файловете се пренасят без ръчни поправки. Указателят `releases/current.json` назовава изданието.
3. Преглеждат се разликите, произходът, проверките и съвместимостта с кода. Release PR се слива с merge commit.
4. Merge към `main` публикува staging. Проверяват се екраните и `/api/releases/current`.
5. След изрично одобрение от собственика таг `vX.Y.Z` върху commit от `main` публикува production по [production процедурата](production-procedure.md).

За връщане на данни се подготвя нов PR с предишното проверено копие. Worker-ът няма операторски API; `/admin/*` връща `404`.
